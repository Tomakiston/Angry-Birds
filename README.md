Recriação do clássico jogo Angry Birds para fim educacionais

---
## 📚 Aprendizados
- Motores de física
- Criação de jogos estilo Physics-Based Projectile Game

## ⚙️ Funcionalidades
- Arrastar pássaro com mouse
- Derrubar a construção e derrotar porcos
- Apertar ESPAÇO para utilizar um pássaro novo
- Reiniciar o jogo no botão Restaurar

## 🛠️ Stack
- JavaScript
- HTML5
- CSS3
- p5
- Matter

## 🚀 Deploy
1. Clone ou baixe este repositório.

```bash
git clone https://github.com/Tomakiston/Angry-Birds
```

2. Abra o arquivo `index.html` em seu navegador.
